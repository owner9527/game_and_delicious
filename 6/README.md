# 《回声》Echo —— 声音驱动解谜冒险（PC 网页版实现）

依据《〈回声〉游戏立项策划案 V1.0》实现的可玩版本。玩家扮演失去视觉记忆的"聆听者"，
在被"大静默"笼罩的城市中，仅凭**探测音、录音、回放、回声叠加**四种声音能力解开谜题、
揭开城市沉默的真相。**游戏内零文字，声音是唯一的信息通道。**

## 运行方式

零依赖纯静态页面，任选其一：

```bash
# 方式一：Python
cd 本目录 && python -m http.server 8777
# 方式二：Node
npx http-server -p 8777
```

浏览器打开 <http://127.0.0.1:8777/>，**请戴耳机**（体验核心是双耳声像定位）。

> 直接双击 index.html（file:// 协议）也能玩，但浏览器可能限制音频自动策略，
> 推荐本地服务器方式。

## 已实现的策划案要点

**核心玩法（第三章）**
- 核心循环：聆听 → 录制 → 回放 → 叠加 → 解锁 → 前进；
- 声音物理映射：回响延迟→距离、音调→大小/材质、响度衰减→材质软硬、音色→身份、声像→方位；
- 机关只响应特定声音：锈蚀铁门（低沉金属撞击）、玻璃桥（清脆高频、声音持续期间实体化）、
  共鸣钟（≥2 秒稳定长音，需录阵风）、声音解构门（同材质高低双频和弦）、终门（三声轨共鸣柱）；
- 静默者：对声音敏感，回放会暴露位置（暴露度指示条），可用诱饵录音引开；
  捕捉 3 次回退子谜题起点，**已录声纹全部保留**；
- 通关：抵达共鸣室对记忆晶石发出 3 次探测充能；收集每关 0–3 枚声之碎片（近处有微光音提示）；
- 评级 S/A/B/C = 时间 40% + 碎片 30% + 回放次数 30%（4.1）。

**内容规模（3.5 难度曲线）**
- 4 章 10 关：教学期（初醒/涟漪/回廊）→ 入门期（和声/静默者/玻璃桥）→
  进阶期（共鸣钟/镜厅·镜像回声）→ 挑战期（交响·多声轨编排 / 大静默的起源·限时逃脱+尾声叙事）；
- 听音训练场：自由录制合成、实时波形可视化（4.2）；
- 每日挑战：按日期种子程序生成谜题（4.2）。

**音频（5.4）**：全程序化合成（金属非谐分部/玻璃簇/水滴啁啾/木石噪声/阵风/声语五声音节/钟），
生成式卷积混响，立体声声像，BGM 低于音效 12dB 且随解谜进度分层，**±200ms 回声延迟校准**
（设置内，针对蓝牙耳机）。

**视觉（5.1/5.2）**：暗灰蓝 #2A3B4C 基底，琥珀金 #F5A623=环境声、青绿 #43C6AC=玩家声、
机关激活暖橙高亮；「声音即光源」——物体被声波照亮才显形；彩色只属于声音。

**系统（第四章）**：本地自动存档（localStorage，子谜题级进度）、8 个成就（回声印记）、
听感等级（经验）与每 5 级解锁的声纹主题、无障碍（声纹可视化开关 / 纯听觉模式 / 震动开关）、
卡关 3 分钟自动出现声纹路径提示、静默者首遇时 15 秒系统示范（诱饵教学）。

## 与策划案的差异（网页版范围说明）

| 策划案内容 | 本实现的处理 |
| --- | --- |
| Unity 2022 LTS / 手游双端 | 采用策划案 1.3 中同为高优先级的 **PC 网页版** 技术路线（Canvas 2D + Web Audio API），零安装即点即玩；触屏虚拟摇杆+按钮已内建，逻辑层与平台无关 |
| 服务端功能（云存档/排行榜/防作弊/埋点） | 单机本地桩：存档落 localStorage；排行榜/云同步未实现（需服务端） |
| 内购/广告/买断（第十章） | 未接入任何支付 |
| 录音最长 10 秒 | 调整为 5 秒上限，保证玻璃桥等机关的节奏紧张感 |
| 回声陷阱（困 60 秒判负） | 未实现该机关类型，失败仅来自静默者捕捉与终章静默之墙 |
| 60 成就 / 每周赛季 | 精简为 8 个本地成就 |
| UGC 关卡编辑器（9.3 远期） | 未实现；关卡为纯数据驱动（`js/levels.js`），扩展只需追加数据 |

## 代码结构

```
index.html        界面层 DOM（菜单/结算/设置/成就，每屏文案 ≤20 字）
css/style.css     视觉规范（配色、400ms 声波缩放切换动效）
js/audio.js       音频引擎：程序化音色、混响、声像、通道预算(16路)、延迟校准、分层 BGM
js/levels.js      关卡数据（10 关+沙盒+每日生成器），机关条件为声明式 req 匹配器
js/engine.js      玩法引擎：声呐视觉、录音/回放/叠加、机关状态机、静默者 AI、评级统计、渲染
js/ui.js          菜单流转、存档、成就、设置、结算
js/main.js        入口
```
