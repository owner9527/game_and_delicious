# 镜像迷城 · Mirror Maze

以"左右镜像联动"为唯一核心机制的 2.5D 横版对称解谜游戏。双子"棱"（左·青）与"镜"（右·橙）被真实之镜分隔在镜轴两侧，用**一套输入同时驱动两个角色**，破解镜像谜城。

> 本作为《镜像迷城立项策划案》（V1.0）的可玩原型实现，对应里程碑 **M0（可玩原型）/ M1（垂直切片）**。

## 运行方式

零依赖纯前端实现，两种方式任选：

1. **直接打开** `index.html`（Chrome / Edge / Safari / Firefox 均可）；
2. 或起本地服务：`python -m http.server 8080` → 访问 `http://127.0.0.1:8080/`。

调试参数：`index.html?debug=1` 解锁全部关卡（供测试）。

## 操作

| 场景 | 按键 |
| --- | --- |
| 同步模式移动 | `A/D` 或 `←/→` |
| 跳跃 | `空格` / `W` / `↑` |
| 碎镜后分控 | `WASD` 控制**棱**（左）· `方向键` 控制**镜**（右） |
| 撤销 / 重开 / 提示 | `Z` / `R` / `H` |
| 暂停 | `Esc` / `P` |

移动端：虚拟摇杆 + 跳跃键，碎镜后双摇杆分控；手柄：左摇杆 + A（碎镜后双摇杆）。

## 已实现（对照策划案）

- **核心机制**：一套输入、双角色、五种镜像模式——完全镜像 / 延迟镜像（0.5s，禅模式 1.5s）/ 反向镜像 / 局部镜像（仅 X，右岸无跳跃）/ 碎镜独立（结界 z 触发，慢动作 0.3s + 全屏碎裂演出）。
- **机关**：同步压力板（保持型）、镜像传送门（对岸对称位出现）、棱镜光束（发射器 / 折光镜 / 棱镜平台 / 水晶接收器）、节拍平台（相位环 + 节拍器音轨）、重力幕帘（翻转重力倒行）、碎镜结界、地刺、检查点、镜之碎片、镜像之门（每岸宽门/窄门两种规格）。
- **关卡**：5 章 30 关手工设计（黎明 → 黄昏 → 森林 → 熔岩 → 终焉），机制渐进解锁，三章一守卫式综合关。
- **系统**：主菜单「游戏说明」（目标 / 操作 / 五种模式 / 机关图例 / 星级 / 贴士）、星级评价（通关 / 碎片 / 步数）、章节与关卡解锁、镜像法则图鉴（随进度解锁 13 条规则）、新手引导浮层、三级渐进提示（卡关 90 秒自动强提示）、暂停 / 结算 / 终章演出、localStorage 存档。
- **表现**：五章主题色、玻璃拟态中心对称 UI、粒子与拖尾、双声道定位音效（左棱右镜，WebAudio 全合成零素材）、每章生成式 BGM、破镜慢动作 + 闪白 + 裂纹、震动反馈、色盲安全形状双编码（左圆右三角）、减少动效模式。
- **平台**：PC 网页（键盘 / 手柄）+ 移动端横屏（触屏），零安装即开即玩。

## 目录结构

```
index.html        入口与界面骨架
css/style.css     玻璃拟态 UI / 双色编码 / 中心对称布局
js/levels.js      5 章 30 关地图数据 + 镜像解析器（左岸定义、右岸镜像、右岸非对称覆盖）
js/game.js        核心引擎：固定步长物理、镜像输入映射器、机关状态机、摄像机、粒子、渲染
js/input.js       键盘 / 触屏 / 手柄归一化输入
js/audio.js       WebAudio 合成音效与生成式 BGM（双声道声像）
js/ui.js          存档 / 菜单 / HUD / 结算 / 图鉴 / 设置
js/main.js        启动入口
tools/validate.js 关卡结构无头校验（node tools/validate.js）
```

## 自动化测试

引擎暴露 `MMGame.debugStep(n)`（固定步长推进，即策划案 6.6 的"输入序列回放"基础）、`MMGame.debugChars()`、`MMGame.debugInfo()`。

浏览器控制台可运行闭环机器人脚本回放通关；`tools/validate.js` 校验全部 30 关的结构完整性（出生点成对、门与板配对、传送门配对、碎片槽位等）。

## 与策划案的差异说明（原型阶段取舍）

- **压力板为"踩下保持"**而非"同时踩压"：单输入镜像联动下，"必须同时踩住"会使纯镜像关无解，改为"各自踩过即保持"，保留"两岸都要踩到"的合作语义；
- **碎镜后不支持撤销跨回镜像状态**，撤销最多回退 3 步（仅位置与机关状态）；
- **星级第三颗的"步数目标"不判负**，仅影响星级（对齐休闲解谜的零惩罚试错原则）;
- 每日挑战、镜像竞速、关卡编辑器、排行榜与联机需服务端，按策划案排期在 M2+ 实现。
