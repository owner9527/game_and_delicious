# 深渊词条 · 肉鸽打宝

依据《游戏设计书 · 四:肉鸽打宝》实现的完整可玩版本。类"暗黑/以撒"的肉鸽:随机地图 × 技能词条组合 × 无尽成长。

**纯前端实现(Canvas 2D),双击 `index.html` 即可游玩,无需服务器与网络。**

## 一、待定项决策(设计书第六节)

| 待定项 | 决策 | 理由 |
|---|---|---|
| 动作 or 站桩 | **动作**(WASD 移动 + 鼠标瞄准射击 + 冲刺无敌帧) | 清屏打宝手感更好,与"以撒"参照一致 |
| 俯视 or 横版 | **俯视角** | 设计书技术选型已定"Canvas 2D 俯视角清屏战斗" |
| 魔幻/科幻/国风 | **魔幻(暗黑地牢)** | 词条/Boss/掉落体系的经典载体 |

## 二、设计书要求 → 实现对照

| 设计书要求 | 实现 |
|---|---|
| 世界大:种子驱动随机地图 | `mapgen.js` 房间连通图生成,种子决定房间数量/敌人配置/障碍;每层结构不同 |
| 系统深:词条池 + 合成规则 | `data.js` 全局词条池(18 数值 + 12 特效词条,武器/被动装备/**主动技能奥术新星**均走词条池),特效词条跨装备**叠加升阶(最高Ⅴ)**;背包**重铸**、拾取**熔合** |
| 够涌现:Build 改变手感 | 连锁闪电/燃烧/剧毒/寒霜/环刃/湮灭/分裂/庇护/狂战/处决/荆棘,叠加后手感质变 |
| 成长长:局内 + 局外 | 局内:升级三选一祝福 + 装备词条;局外:魂晶 → 深渊祭坛 10 项永久强化(含复活) |
| Canvas 2D 俯视清屏 | 单画布 1280×832,自研矢量渲染(无外部素材) |
| 数据表驱动 | 词条/武器/敌人/精英/Boss/祝福/局外升级全部是 `data.js` 中的表 |
| 局内+跨局双存档 | `save.js`:`localStorage` 两个 key,局内进度自动存(可"继续冒险"),局外魂晶永久 |
| 里程碑 | 单房间战斗 ✅ 词条掉落与 Build ✅ 多房间种子生成 ✅ Boss 战(每 5 层,3 领主循环强化)✅ 难度曲线 ✅ 局外成长 ✅ |

## 三、操作

- **WASD/方向键** 移动 · **鼠标** 瞄准 · **左键(按住)** 射击
- **Q** 主动技能(奥术新星,需通过祝福/词条解锁) · **空格/Shift** 冲刺(短暂无敌) · **E** 拾取/开箱/祭坛/下楼 · **Tab** 背包与属性 · **Esc** 暂停 · **M** 音效

## 四、核心循环

进入随机层 → 清怪(门锁→开门)→ 拾取金币/药水/装备词条 → 找 **↓ 下一层** → 每 5 层打深渊领主 → 死亡结算魂晶 → 祭坛永久成长 → 更深一层。装备稀有度:破旧→精良→稀有→史诗→**传说(5 词条,必带特效)**,层数越深掉落越好。

## 五、扩展指南(加玩法 = 加一行数据)

- **加词条**:`data.js` → `AFFIX` 加一项(数值词条给 `per[5]` 数组 + `apply`;特效词条给 `mech(l)` 并在 `game.js` 的命中结算中消费)
- **加武器**:`WEAPONS` 加一行(支持 count/spread/aoe/wave 字段组合)
- **加敌人**:`ENEMY_TYPES` 加一行,选 AI 类型(chase/bat/ranged/bomber/charger/caster)
- **加精英词缀**:`ELITE_MODS` 加一行
- **加 Boss**:`BOSSES` 加一行,从已有攻击模式(radial/spiral/homing/charge/summon/rings/sweep)中组合
- **加祝福/局外升级**:`BLESSING_POOL` / `META_UPGRADES` 各加一行

## 六、文件结构

```

style.css       界面样式
js/util.js      数学工具 + 种子随机(mulberry32)
js/audio.js     WebAudio 合成音效(无素材)
js/data.js      ★ 全部数据表(词条池在此)
js/save.js      局内/局外双存档
js/loot.js      掉落生成 + Build 数值合成
js/mapgen.js    种子随机房间连通图
js/entities.js  敌人AI / 弹幕 / 特效 / 拾取物
js/ui.js        HUD / 小地图 / 菜单 / 弹窗
js/game.js      战斗核心循环 / Boss / 渲染
js/main.js      启动 / 输入 / 主循环
```
