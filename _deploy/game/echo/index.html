游戏说明

🌍你是聆听者

世界被「大静默」笼罩，一片漆黑。声音是你唯一的光——用耳朵代替眼睛，穿过每一关，抵达深处的记忆晶石，对它发出探测音完成三次充能。

🔊三种声音能力

探测音：点按屏幕 / 空格，声波点亮周围轮廓。
录音：长按录音键 / R，录下附近的声音（走近发声物、撞击它们）。
回放：点回放键 / E 复现声音——机关只响应特定的声音。

👂听声辨物

回声越迟 = 距离越远；音调越低 = 物体越大；音色揭示材质：金属、玻璃、流水、阵风……立体声的左右方位指示声源方向。

🗝️机关与和声钥匙

锈蚀铁门要低沉的金属撞击；玻璃桥要清脆的高频水声（声音持续期间桥才实体化）；共鸣钟要两秒以上的稳定长音。选中多个声纹再叠加，可以组成「和声钥匙」。

👤静默者

它们看不见你，但听得见你。回放声音会暴露位置（右侧指示条升高）——用投掷诱饵把声音扔到远处引开它们。被抓三次只回到本段起点，已录的声纹不会丢失。

💎收集与评级

每关藏有 3 枚「声之碎片」，靠近时会听见微光音。结算按通关时间、碎片、回放次数评级 S / A / B / C。卡住超过 3 分钟，会出现金色的声纹箭头为你指路。
