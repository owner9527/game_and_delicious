# 星火拓荒 · 无尽之地

一款按《游戏设计书 · 二:生存建造》实现的**类"缺氧/饥荒/环世界"生存建造游戏**,纯原生
HTML5 Canvas 2D + JavaScript,零依赖、零构建、零素材(全部画面程序化绘制)。

## 怎么玩

**直接双击 `index.html`** 即可开始(也可以用任意静态服务器打开,如
`python -m http.server 8125`)。浏览器建议 Chrome / Edge。

- 开始界面可输入**世界种子**生成可复现的大陆;留空则随机。
- 存档自动写入浏览器 localStorage(每 60 秒自动保存 + 手动保存按钮 / F5)。

| 设计书要求 | 实现 |
| --- | --- |
| 世界大:程序化随机分块生成 | 16×16 格分块,值噪声 FBM 生成地形(水域/沙滩/草原/森林/矿脉/水晶),每块独立资源密度;按种子动态生成,地图无边界 |
| 系统深:科技树+多种资源组合 | 5 时代 8 项科技;木/石/铁矿/煤/水晶/浆果/小麦/面包/铁锭 9 种资源;配方模块化(`data.js` 注册即生效) |
| 成长长:篝火→自动化工厂 | 篝火 → 仓储/农田/厨房/冶炼炉 → 炮塔/实验室 → 自动采矿机/无人机站 → 星界信标;localStorage 长线存档 |
| 够涌现:天气/事件随机 | 事件表+状态机:丰润之雨 / 矿脉涌动 / 兽群低吼 / 神秘旅者;昼夜循环、蚀影兽夜袭、火光庇护 |
| ECS 架构 | 轻量 ECS(`core.js`):实体=组件袋,系统按帧处理 采集→运输→建造→生产 循环 |

## 核心循环

1. **采集**:砍树采石,右键标记资源,招募工人(浆果×8+木头×15)让他们自动干活。
2. **生存**:饥饿会掉血;浆果应急,农田+厨房的面包才是长久之计。夜晚蚀影兽惧怕火光——
   篝火是庇护所,木墙阻挡,弩炮塔防守。
3. **科研**:工作台/实验室产出科研点(工人操作加速),解锁冶炼与自动化。
4. **自动化**:冶炼炉→自动采矿机骑在矿脉上持续开采→无人机站释放无人机无视地形采集。
5. **胜利**:积攒铁锭×100 + 水晶×50 + 石头×100,点亮星界信标。

## 代码结构

```
index.html        页面骨架与 UI DOM
css/style.css     HUD / 面板样式
js/core.js        工具:随机数/值噪声/ECS 框架/粒子/音效(WebAudio 合成)
js/data.js        数据驱动:物品/建筑/配方/科技/事件表/平衡数值
js/world.js       程序化分块生成 / 资源节点 / A* 寻路
js/actors.js      玩家/工人状态机/蚀影兽/无人机 AI 与工作台
js/buildings.js   仓储池/蓝图施工/配方生产链/农场/采矿机/炮塔/科研
js/systems.js     昼夜循环/饥饿/夜袭/事件状态机/灯光汇总
js/render.js      Canvas 渲染:地形/建筑/实体/灯光遮罩/天气/小地图
js/ui.js          HUD/建造面板/科技树/消息/结算界面
js/save.js        世界状态序列化(脏块+实体+建筑+科技)
js/main.js        初始化/输入/主循环
```

加新内容 = 在 `js/data.js` 注册新物品/建筑/配方/科技条目,引擎不变。
