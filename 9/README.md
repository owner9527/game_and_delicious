# 星穹拓荒 · Stellar Frontier（H5 可玩版）

依据《星穹拓荒》立项策划案（V1.0）实现的可玩网页版，对应策划案目标平台中的 **PC 网页（H5）端**。
无需安装任何依赖：**直接双击 `index.html` 即可游玩**（也可用任意静态服务器托管）。

## 运行

```
双击 index.html
# 或（开发模式，禁用缓存）
python server.py            # 然后访问 http://127.0.0.1:8619
```

## 测试

```
node test/headless.js       # 35 项无头逻辑测试（生成确定性/经济/事件/胜负/序列化）
```

## 操作

- 鼠标拖动 / WASD 平移，滚轮缩放；触屏单指拖动、双指捏合
- 点按建筑查看详情与修复/拆除；建造菜单选择后在地表放置（Shift 连放）
- 空格暂停，1/2/3 变速，B 建造，T 科技，Esc 取消/关闭

## 代码结构

```
index.html        界面骨架（HUD/面板/弹窗）
css/style.css     全息 HUD 玻璃拟态风格（策划案 §5.3）
js/rng.js         xmur3 + mulberry32 种子随机（跨端一致性基础）
js/data.js        全部静态数值表：恒星/行星/建筑/科技/事件/成就/遗产
js/gen.js         程序化生成：星系→行星→地表→降落点（纯函数）
js/audio.js       WebAudio 程序化音效
js/game.js        模拟核心：经济/殖民者/事件/威胁AI/胜负/序列化
js/render.js      Canvas 渲染：地表/建筑/单位/粒子/昼夜/小地图
js/ui.js          HUD/面板/弹窗/输入/星图/结算
js/main.js        元进度持久化 + 主循环
server.py         开发用禁缓存静态服务器（正式部署不需要）
test/headless.js  无头逻辑回归测试（35 项断言）
```
