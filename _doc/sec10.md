### 3.10 10 情绪花园 · Emotion Garden

**现状**
治愈系情绪表达游戏（纯前端零依赖）：用颜色 / 文字 / 音乐说出此刻心情，本地解析成 6 类情绪，生成 24 种 × 3 变异的程序化植物，按 5~24 小时真实时间经五阶段开花。垂直切片完成度很高——表达 → 播种 → 照料 → 生长 → 收获 → 生态闭环、双副本存档、72 图鉴、26 成就、12 章"心灵旅程"、8 个生态事件、冥想、回顾信、字号 / 高对比 / 低刺激设置都已落地；离屏花瓣叶片精灵与 8 种花形也在上一轮完成了美术升级，分层清晰、注释完整。

**主要问题**
1. **分享卡把玩家写的原句画进了 PNG**（`ui.js:823` 绘制 `pl.note`），与界面上「分享的是花，不是心情的原文」以及 README 里的合规承诺**直接矛盾**——实测导出的卡片上出现了「我今天特别难过想一个人待着」。对一款以"安全表达情绪"为卖点的产品，这是最严重的一类问题。
2. **颜色路径名存实亡**：`ui.js:284` 用中文词条的 `cat/intensity` 覆盖了 `parseColor` 的结果。实测选纯红 8°、再点「平静如水」，得到 `calm` / 强度 5，但颜色值仍是红色的 -0.85——**类别与数值自相矛盾**；而且不点中文词条就无法继续，等于强迫用户从 8 个中文短语里挑一个。
3. **凋谢不可挽留，且文案不实**：`checkWither` 只看绽放后 72 小时真实时间，浇水 / 剪枝 / 道具**全部无效**（实测刚浇过水仍枯萎）；×360 加速时存活期只有 12 分钟；而回顾信却写着「替你浇过水」。
4. **目标链互锁且不可达**：Lv30 需 152,978 经验（≈4,500 株）、Lv50 需 587,651（≈17,000 株），而 64 格满园最优配比下实测生态评分上限只有 852——策划案里的 1000 与成就 `a_eco750` 都够不到。
5. **玩家那一株没有被记住**：`dex` 只存 `{n, variants, first, species}`（`game.js:442`），图鉴缩略图用 `'dex'+物种id` 的**假种子**重绘（`ui.js:513`），日记又在 400 条处硬截断——"独一无二的那一株"和"回忆"都没留住。

**优化建议**

- **P0｜分享卡默认不写原句**：在 `ui.js:823` 增加「在分享卡上写这句话」开关（**默认关**），并把弹窗文案改成如实描述。**为什么**：隐私承诺与实际行为不一致，是这类产品不能接受的；默认关 + 显式勾选既保住隐私又不剥夺表达欲。
- **P0｜让色轮真正生效**：改为 `parseColor` 直出，主按钮换成「就用这个颜色」，8 个中文词条降为**可选的校准**。**为什么**：一次解决三个问题——颜色路径名副其实、色盲 / 低文字用户不必强行选中文短语、也消除了类别与数值自相矛盾。
- **P0｜给"失去"留出口**：凋谢时提供「留在花园」（进装饰层永久陈列 + 保留原句）；`×360` 只加速生长、**不加速 `bloomedAt`**；删掉回顾信里「替你浇过水」的不实承诺。**为什么**：治愈系游戏里"不可挽回的失去 + 一句假话"是最伤人的组合。要么让它可挽留，要么让它诚实。
- **P0｜修移动端布局**：`garden.js:668/759` 的石板径与围栏在 390px 宽下实测挤到 180/210、176/214 **完全重叠**，应改按宽度比例排布或窄屏隐藏；工具条补 `env(safe-area-inset-*)`；窄屏限制最大网格（8×8 时单格仅 43.9px、缩放触底 0.55）。
- **P1｜重排成长曲线**：`expNeed` 从 `60·l^1.6` 降到 `60·l^1.15`（Lv30 从 15 万降到约 3.5 万），地块扩张改挂「累计收获」，生态评分满分重标为 850。**为什么**：现有曲线需要种 4,500 株才能到 Lv30，这已经不是"长期目标"而是"不可能"。
- **P1｜图鉴记住种子与原句**：`dex` 增存首次 `seed` 与 `note`（可隐藏），缩略图改用**真实种子**重绘，植物详情加「生成纪念卡」复用 `openShare`。**为什么**：这是"每一株都独一无二"这个卖点的落地；用假种子重绘等于每株看起来都一样。
- **P1｜日记按月分片存储**替代 400 条硬截断；设置里显示「已记录 N 天 / 占用 KB」；增加导出 txt/csv 与「只清空情绪原文、保留花园」。**为什么**：情绪日记的价值随时间增长，截断等于主动销毁用户资产。
- **P1｜可访问性补课**：全站 `tabindex`/`aria` 数量为 0、无 Esc 关模态、日历圆点只有颜色、`--ink-l` 对比度仅约 3.2:1、低刺激模式不作用于 CSS 动画、viewport 禁缩放。建议补键盘激活与 Esc、圆点加 `●〜▽▲✳☾` 符号冗余、说明文字默认加深、允许缩放。**为什么**：这款游戏面向的正是情绪敏感人群，可用性门槛应当比其它几款更低。
- **P1｜音乐补深度**：`MusicPlayer.play`（`audio.js:142`）用 `Math.random()` 抽音，实测同一首曲两次播放音符不同、全曲只有约 10 个音。改用 `EG.RNG(track.id)` 生成确定性旋律，曲库标出情绪与关键片段，导入支持选段分析。**为什么**：音乐是这款游戏的三条表达通道之一，现在它既不可复现也不成曲。
- **P1｜音频开关修正**：设置里关 BGM 只调用 `BGM.stop()`（仅清定时器），环境底噪仍在 `bgmGain=0.5` 下循环。让 `stop()` 归零增益并停掉 `_noise`。**为什么**：这是"关了没关掉"的典型可用性 bug。
- **P2｜交互细节**：收获与开垦地块单击即不可逆（`ui.js:175`、`main.js:118`）应二次确认；调光 60min / 旋律 20min / 剪枝 4h 的冷却需显示倒计时；`plant()` 中 `record()` 与 `bumpTask('record')` 重复导致"种一株"任务记 2 次；教学植物按钮写「浇水 +8」实际给 40。
- **P2｜性能**：实测空园约 26~30ms/帧、满园 64 株约 40ms/帧，主要开销是**每帧重建**天空 / 山 / 草 / 装饰（约 40 个径向渐变 + 近 200 条草叶 + 90 颗星 + 12 株装饰花）。建议把静态背景烘焙到离屏画布，仅在季节 / 昼夜 / 生态变化时重建。**为什么**：这是本合集里最"吃"性能的一款，而它的画面本来并不需要每帧重画。

**这条最值得先做**：分享卡的原句问题。它是**唯一一条"做错了会伤害用户"**的建议，优先级高于所有体验优化——把开关默认关掉、文案改对，改动量很小，但性质完全不同。
