### 3.2 02 星火拓荒 · 无尽之地

**现状**
纯原生 Canvas 2D 生存建造游戏，10 个 JS 模块约 195KB，零依赖零素材。完成度很高：16×16 分块的无限大陆、9 种资源、13 种建筑、8 项科技、昼夜 / 下雨 / 随机事件 / 蚀影兽夜袭、工人与无人机 AI、脏块差分存档都在跑；右键快捷建造、B/T/H 快捷键、5 页指南齐全。**渲染层（预烘焙贴图、明暗×色相二维色板、光影遮罩、环境粒子）与数据驱动层是本合集里的亮点**；实测地形生成 0.08ms/块、新建存档仅 2KB。

**主要问题**
1. **手机端零触控**：`main.js` 只绑鼠标事件，快捷建造菜单只在 `e.button === 2` 的 `mouseup` 里打开（`main.js:310`）——触屏没有右键，于是**建造 / 框选 / 取消三条主线全断**。
2. **仓储满仓会静默饿死**：仓储是全局总上限（`Pool.add` 按 `cap() − total()` 卡总量，`buildings.js:25`），满仓时**任何物品都进不去**；厨房产出的面包卡在建筑自己的 `buf.out` 里，而 `Pool.eat` 只读 `G.pool`（`buildings.js:43`）——**满仓即食物断供**，20 秒模拟里 0 条提示。
3. **存档单槽，且"采空区块"不落盘**：`save.js:27` 会跳过 `nodes.size === 0` 的脏块，实测**采空的块读档后会重新长出 93 个资源节点** → F5/F9 可以无限刷资源。
4. **蓝图不可取消**：`place()` 先扣费，之后点蓝图只会让玩家去锤（`actors.js:141`），拆除按钮只存在于"已建成建筑"的详情面板里。
5. **打开面板不暂停，首个夜晚来得太快**：打开科技树/指南时 `Systems.update` 照跑（实测 `pausedWithTechOpen = false`）；开局 `dayFrac = 0.32`（`main.js:53`），约 100 秒后就迎来第一波夜袭（`systems.js:56`）。
6. **信息与指挥层缺失**：科技树无搜索无队列（8 项共 1455 科研点）、没有工人名单/血量/任务、小地图固定 82×82 格且不可点（`render.js:2056`）、相机**永久跟随玩家**（`render.js:443`）、天黑只有一条日志加音效。

**优化建议**

- **P0｜补触控层，把右键的三件事搬上触屏**：长按弹出快捷建造菜单、单指点按采集/落点、加一个「标记模式」按钮替代框选；同时给 canvas 加 `touch-action:none` 并按 `devicePixelRatio` 缩放（`render.js:65` 现在直接用 `innerWidth`，高 DPI 屏会发糊）。**为什么**：现在手机上**完全无法建造**，而且没有任何长按之类的替代入口。
- **P0｜仓储溢出保护**：给食物与关键物资留保底格位（例如 20% 容量只收食物），或满仓时按优先级替换；满仓必须 `UI.msgFull` 播报「仓储已满，X 已停产」；并允许玩家与工人直接吃建筑 `buf.out` 里的食物。**为什么**：**"满仓静默饿死"是致命且无从察觉的失败**——玩家会觉得游戏坏了。
- **P0｜修存档并扩成多槽**：`serialize()` 改判 `ch.dirty`，把采空块写成空节点表（或标 `empty:true`）以免读档复活；加 3 个槽位与 `visibilitychange`/`beforeunload` 自动保存。**为什么**：既杜绝读档刷资源，也让"关掉页面不丢档"成立。
- **P0｜蓝图可取消 + 批量建造**：点击蓝图即取消并**全额退款**；右键拖拽沿直线批量下蓝图并按仓储余量截断；保留 Shift 连续放置。**为什么**：误放的代价现在太高，而围墙/仓储只能一格一格点。
- **P1｜面板暂停 + 夜间预警 + 小地图交互**：开面板时把 `dt` 归零（或 ×0.1）；时钟旁显示「距天黑 mm:ss」，夜袭前 20 秒 HUD 闪红并给屏幕边缘方向箭头；小地图可点击跳转/缩放，标出工人（蓝）、已标记资源（白）与火光范围。**为什么**：现在"看面板等于送死"、天黑毫无准备、小地图只是装饰。
- **P1｜工人指挥与信息**：加工人列表（名字 / 血量 / 饥饿 / 当前任务 / 位置），点列表可指派其去指定格（临时 job 优先级 9），加「宵禁 / 回营」开关让工人入夜不外出；顺手修 `wFlee` 里"篝火旁回血"其实是无条件回血（`actors.js:470`）。**为什么**：工人是核心资产却是个黑箱。
- **P1｜科技与建造面板**：科技面板加研究队列（攒够自动解锁）与「全解锁还需约 x 分钟」的估算；建造面板补「缺什么」一键跳到资源标记；把 1455 点总成本下调 20%~30%，或把工作台 0.5 → 0.8 科研点/秒。**为什么**：中后期现在几乎是纯挂机等科研点。
- **P1｜性能热路径**：`getLights()` 被 `nearLight` 逐怪重算（24 怪 × 2 = 48 次全量 `ECS.query` + 数组分配，而渲染层其实已缓存一份）→ 改为按帧缓存；`findPath` 的 open 表线性扫描（`O(n²)`，`maxExp 2600`，`world.js:164`）→ 换二叉堆并给工人分帧寻路；`Pool.cap()` 每次都 `countDone` 全量查询（`buildings.js:24`）→ 改计数器；光照遮罩 `lcv` 改半分辨率再放大。**为什么**：实测无 GPU 软件渲染下夜间遮罩 9.3ms/帧、压力场景（60 建筑 + 10 工人 + 24 怪）**106 → 23fps**，低端设备明显吃亏。
- **P2｜可访问性**：资源筹码补 1~2 字缩写与 `aria-label`（现在只有色点）、加色盲配色档、提供 100%/125% UI 缩放（字号固定在 10~11px）、音效开关持久化到 localStorage、支持键盘建造（方向键移光标 + Enter 落点、数字键选建筑）。**为什么**：画布内玩法**100% 依赖鼠标与颜色**。
- **P2｜资源再生与末局长线**：树木 / 浆果丛缓慢再生，或加"树苗"建筑；自动采矿机枯竭后自动寻找最近的同类矿脉；末局需要 100 铁锭 = 200 铁矿 + 100 煤，而采矿机产出仅 1 单位/8 秒。**为什么**：浆果丛不回头会让前期食物不可逆枯竭，末局又变成纯等待。

**这条最值得先做**：手机触控。它是这份意见书里**唯一一条"整款游戏在主流设备上完全不可玩"**的问题，而且改造面并不大——输入事件集中在 `bindInput` 一处。
