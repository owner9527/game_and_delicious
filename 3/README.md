# 拓城记 · 中古殖民模拟

按《游戏设计书三:经营建设·殖民模拟》实现的完整可玩游戏。造物主视角,Canvas 2D 自上而下网格城市,
居民由需求驱动:住房、食物、娱乐、医疗、信仰。规划道路与建筑,满足他们的需求,见证村庄在繁荣与
崩溃之间涌现成长。

## 快速开始

**方式一(推荐)**:双击 `index.html` 即可在浏览器中游玩(Chrome / Edge)。

**方式二(本地服务器)**:双击 `启动服务器.bat`(8124 端口,自动打开浏览器),
或手动执行:

```bash
python serve.py 8124     # 然后访问 http://127.0.0.1:8124/
```

进入游戏后会自动弹出 6 页「游戏说明」向导;顶栏「❓ 说明」可随时重新打开,
取消勾选"进入游戏时自动打开"后则只在手动点击时显示。

## 核心规则(需求-供给网络)

- **居民需求**:食物、住房、娱乐、医疗、信仰(信仰自「城镇」阶段起生效)。每日结算满足度,加权成幸福度。
- **道路是命脉**:所有服务建筑必须**毗邻道路**,居民沿路前往(Dijkstra 按通行代价丈量半径:路面 1、野地 4)。
- **人口涌现**:幸福高 → 新生儿与移民迁入;幸福低 → 居民离弃;饥荒瘟疫 → 健康崩溃 → 连锁死亡。
  人口有**硬上限 320**,且每日增长不超过当前人口的 **4%**(至少 1 人);住房留出 12% 余量才会继续接纳移民。
- **可再生自然资源**:森林 / 矿脉 / 猎物各格都有"蓄积",生产建筑每天从附近资源格取材,
  资源格按季节 logistic 生长(越接近满蓄积长得越慢),每 40 天有一次矿脉勘探刷新。
  砍得比长得快,林子会变稀、兽径会空掉;停采后自己长回来。**建筑永远不会把资源格采到 30% 以下**(留种)。
  右侧「城市」页的「可再生资源(已解锁领地内)」显示蓄积 / 生长 / 采集 / 净变化。
- **经济闭环**:人口税金(受幸福度与教育加成)→ 建造费用与服务维护费;交易所自动盈余出售/缺粮回购。
  人手不足时按各建筑的用工需求**比例分摊**(医疗 > 粮食 > 材料 > 民生 > 娱乐 > 信仰),
  不会再有建筑拿到 0 人而"建了没收入"。仓储满了会明确提示"产出被浪费"。
- **季节**:春夏秋农田 95%/110%/130%,**冬季 10%**(牧场 70%)——秋冬囤粮是生存关键。
- **阶段成长**:村落 → 城镇(人口 40 + 幸福 55)→ 城市(人口 120 + 幸福 60 + 学堂)。逐级解锁建筑与外环领地(3×3 区块,初始 1 块)。
- **事件**:瘟疫 / 火灾 / 盗匪 / 暴风雪 / 丰收庆典 / 流浪商队 / 移民潮 / 风调雨顺。水井防火防疫,治安所防盗。沙盒难度无灾祸。
  重大事件会弹出**可读横幅**并默认**自动暂停**,让玩家看清发生了什么(可在「城市」页关掉)。
- **目标链**:11 个里程碑引导你从 8 格路一路建设到人口 300 的伟大王国。

## 设计书待定项的实现决策

| 待定项 | 决策 |
|--------|------|
| 主题 | **中古城镇**(与 Canvas 程序化美术最契合) |
| 时间缩放 | **实时节奏 + 日结算**(1 天 ≈ 4 秒,可暂停 / 1× / 2× / 3×) |
| 难度 | **双模式**:标准(含灾祸事件)/ 沙盒(仅良性事件),开局选择 |

## 调平衡

设计书要求"经济数值用数据表配置"——全部数值集中在 **`js/config.js`**:

- `BUILDS`:建筑成本、产量、服务容量/半径、维护费、员工数(新增建筑在此注册即自动纳入需求-供给网络)
- `ECON`:税金、耗粮、通行代价、一天时长、速度档位、人口上限与增速、同屏行走上限
- `NAT`:森林 / 矿脉 / 猎物的蓄积上限、四季生长速率、采集半径、留种下限(floorFrac)、勘探刷新周期
- `SEASONS` / `STAGES` / `ZONE_COST` / `EVENTS` / `OBJECTIVES`:季节、阶段、领地、事件、目标链
- 需求权重与幸福度公式:`js/residents.js`(`hapWeights` / `hapOf`)

## 代码结构

```
index.html        入口与 UI 骨架
css/style.css     界面样式
js/
  utils.js        随机数/噪声/工具
  config.js       ★ 全部数值表(建筑/需求/阶段/事件/目标/可再生资源)
  map.js          世界生成(噪声地形)+ 3×3 区块领地
  path.js         多源 Dijkstra(服务范围)+ A*(居民行走)
  resources.js    ★ 可再生自然资源层(森林蓄积/矿脉/猎物 + 采伐与再生)
  buildings.js    放置/拆除/员工调配(按需比例分摊)/服务分配/住房分配
  residents.js    需求满足/幸福度/健康瘟疫/迁移生死/行为与任务文本
  economy.js      生产(受资源蓄积约束)/税金/维护/仓储/交易/溢出统计
  events.js       随机事件与修正系数
  sim.js          时钟与每日结算编排/日报/阶段/目标
  render.js       Canvas 渲染(地形四季/资源增量重绘/野物/建筑/行人目的/浮动产出/覆盖层/小地图)
  ui.js           HUD(涨落动画)/建造面板/信息面板/居民面板/悬浮提示/事件横幅/弹窗
  save.js         localStorage 存档(手动 + 每 10 天自动;v1 旧档缺 nat 字段会优雅重建资源层)
  main.js         启动与主循环
serve.py          开发用 no-cache 本地服务器
```

## 存档兼容

存档版本仍为 `v1`。新增字段(`nat` = 自然资源蓄积、建筑的 `gt` = 猎场格数)都是**可选**的:
读取没有 `nat` 的旧档时会按地形重新生成资源层(全部满蓄积附近)并继续游戏,不会报错或丢进度。
