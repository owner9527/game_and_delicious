# 情绪花园 · Emotion Garden（网页版）

> 依据《情绪花园》游戏立项策划案 V1.0 实现的可玩网页版垂直切片。
> **一句话：把情绪种进土里** —— 用颜色、文字或音乐表达此刻的心情，它会变成一颗独一无二的种子，在你手里慢慢开花。

## 如何运行

**方式一（最简单）**：直接双击 `index.html`，用 Chrome / Edge 打开即可。
**方式二（推荐）**：在本目录启动任意静态服务器后访问，例如：

```bash
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

无需安装任何依赖，零外部资源，完全离线可玩。存档保存在浏览器 localStorage（键 `eg_save_v1`，自动双副本备份）。

## 网页版相对策划案的裁剪说明

策划案面向 Unity 双端产品；本网页版是其中 **WebGL 网页端形态的可玩验证版**，以下内容按"垂直切片"原则裁剪或简化：

- 云存档/排行榜/好友浇灌（需服务端）→ 本地存档；乐园集市等社交玩法未包含
- 内置曲库为 12 首（策划案 60 首）合成旋律示意；导入音乐仅本地分析、不上传
- 主线 12 章→12 个引导任务；成就节选 26/60；生态事件 8/18
- 生长周期保留真实时长（5–24h），设置中提供 ×60 / ×360 演示加速

## 操作说明

- **种植**：底部工具条「🌱 种植」→ 选颜色/写一句话/选音乐 → 确认解析 → 点亮起的空地播种
- **照料**：点任意植株 → 浇水 / 调光 / 旋律 / 倾听（说一句话给它）/ 剪枝 / 换盆
- **收获**：绽放后点「🌸 收获」再点植株；72 小时不收会自然凋谢（化作纪念，可用记忆喷雾还原）
- **分享**：「📷 分享」生成植物卡 / 年轮分享卡（PNG 下载）
- **设置**（右下角）：时间流速、音频、字号、低刺激、冥想模式、重置花园
